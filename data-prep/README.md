# Datenpflege für Bel-Ami v2

Dieser Ordner enthält die Roh- und Zwischenstufen für die Visualisierung.

## Kernstruktur
- 01 texte: Kapiteltexte
- 03 output: finale Kapiteldaten für die Visualisierung
- 05 bereinigen: erzeugte JSON-Dateien für Karten, Routen und Vergleich

## Arbeitsweise
- Die eigentliche Darstellung nutzt vor allem die finale JSON-Datei pro Kapitel.
- Die Verarbeitungsskripte bleiben erhalten, aber die Projektstruktur ist bewusst reduziert.
