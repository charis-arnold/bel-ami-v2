# Bel-Ami v2

Dieses Projekt visualisiert die Route von Georges Duroy aus «Bel-Ami» als generative Kartografie. Die Struktur ist bewusst schlank gehalten:

- Darstellung: index.html, sketch.js, style.css
- Datenaufbereitung: datenbereinigung.js
- Datenquellen: kapitelXX-stationen.json, kapitel-routen-uebersicht.json, kreisvergleich-orte.json
- Optional: sonifikation.js und kapitel01-sonifikation.json

Die Arbeit folgt einem CAS-Setup: klar, reduziert und nachvollziehbar.

## Ordnerstruktur
- data-prep/: Textgrundlagen und Verarbeitungsschritte
- data-prep/export/: optionale GIS-Arbeitsdateien
